# Бэклог продукта FS.Booking

Список идей и улучшений для будущих версий.

## Высокий приоритет

- Смена языка интерфейса (русский / английский)
- Экспорт отчётов в Excel
- Восстановление пароля через email
- Логирование действий пользователей
- Разграничение прав внутри роли «Администратор»

## Средний приоритет

- Тёмная тема оформления
- Уведомления о предстоящих бронях
- Интеграция с Google Calendar
- Отмена брони клиентом
- Учёт рабочего времени сотрудников

## Низкий приоритет

- Мобильная версия (Kivy)
- Веб-версия (Flask + HTML)
- REST API для внешних интеграций
- Резервное копирование БД по расписанию

## Известные баги

- При большом количестве броней таблица медленно обновляется
- PDF-отчёт не поддерживает многоколоночную вёрстку
