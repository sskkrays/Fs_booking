Руководство пользователя
========================

Установка
---------

1. Установите Python 3.11+ с официального сайта.
2. Скачайте проект: https://github.com/sskkrays/Fs_booking → **Code** → **Download ZIP**.
3. Распакуйте архив.
4. Откройте терминал в папке проекта.
5. Установите зависимости: ``pip install -r requirements.txt``.
6. Запустите: ``python fs_booking.py``.

Учётные записи
--------------

- **admin / admin123** — администратор
- **client / client123** — клиент

Основные функции
----------------

- Создание брони
- Редактирование брони
- Удаление брони
- Экспорт отчёта в PDF
