# FS.Booking

Приложение для бронирования залов на Python (PyQt5 + SQLAlchemy).

## Установка

pip install -r requirements.txt

## Запуск

python fs_booking.py

## Учётные записи

| Логин  | Пароль    | Роль            |
|--------|-----------|-----------------|
| admin  | admin123  | Администратор   |
| client | client123 | Клиент          |

## Функционал

- Авторизация и регистрация пользователей
- Разделение ролей: администратор и клиент
- Управление залами, оборудованием, статусами
- Создание и редактирование бронирований
- Календарь броней
- Отчёты с экспортом в PDF
- Справочники: залы, оборудование, статусы, пользователи
